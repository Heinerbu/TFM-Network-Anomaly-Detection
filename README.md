# TFM-Network-Anomaly-Detection
Development and evaluation of a network traffic anomaly detection framework using machine learning techniques applied to connection flow data.

# Detection of Network Traffic Anomalies Using Machine Learning

Master's Thesis

Author: Heiner Fernando Buitrago

## Abstract

This project presents a methodology for detecting anomalies in network traffic using unsupervised machine learning techniques.

## Objectives

- Process and clean network traffic data.
- Extract relevant features.
- Train anomaly detection models.
- Evaluate detection performance.

## Repository Structure

- notebooks/: Experimental notebooks.
- docs/: Supporting documentation.
- datasets/: Dataset information.

## Methodology

1. Data preprocessing
2. Feature engineering
3. Anomaly detection
4. Experimental evaluation
