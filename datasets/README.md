# Dataset

This project uses the IoT-23 dataset for the experimental evaluation of anomaly detection models.

## Dataset Source

The dataset can be obtained from the official STRATOSPHERE IPS project:

https://www.stratosphereips.org/datasets-iot23

## Citation

Sebastian Garcia, Agustin Parmisano, & Maria Jose Erquiaga. (2020). IoT-23: A labeled dataset with malicious and benign IoT network traffic (Version 1.0.0) [Data set]. Zenodo. http://doi.org/10.5281/zenodo.4743746”

## Repository Policy

The dataset files are not included in this repository due to their size.

Researchers can download the original data directly from the official source and follow the preprocessing steps described in the notebooks.
